# MCP Tools

## adr.create

Creates an Architecture Decision Record from title, context, decision and consequences.

## well_architected.checklist

Generates a review checklist across all six AWS Well-Architected pillars.

## threat_model.generate

Proposed tool that creates an initial threat model from assets, actors and trust boundaries.

## cost_model.review

Proposed tool that maps architecture components to cost drivers and FinOps questions.
